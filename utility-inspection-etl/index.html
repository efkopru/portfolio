Utility inspection data pipeline

Automated helicopter-track, work-order, and inspection data processing for an electric utility.

Professional work

Problem

Structure-inspection analytics depended on operational records arriving from multiple sources and recurring enterprise geodatabase refreshes.

My contribution

I engineered and maintained the ETL workflow, connected helicopter tracks with work-order and inspection records, and orchestrated publication to ArcGIS Portal.

Result

The automated pipeline completed 30+ monthly production executions and eliminated two hours of manual work per run. Enterprise geodatabase refresh processing time decreased by 80% per run.

Tools and methods

  • Python
  • Selenium
  • ArcPy
  • SQL
  • ArcGIS Portal

Independent consulting · September 2022 to August 2025

The execution count belongs to the automated pipeline. Client records, infrastructure locations, credentials, and source code are not distributed with this case study.

How it works

  • Ingest operational records and helicopter tracks through Selenium and Python workflows.
  • Refresh enterprise geodatabase tables with controlled truncate-and-append processing.
  • Calculate inspection-based jobs and priorities, then publish refreshed data for analysis in ArcGIS Portal.
