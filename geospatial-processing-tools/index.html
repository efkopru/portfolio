Raster and document processing utilities

Python utilities for PDF page conversion and source for raster-processing packaging.

PDF conversion source ↗Raster packaging source ↗

Public code

Problem

Geospatial workflows often begin with document conversion or raster preparation before analysis can start.

My contribution

I published PDF conversion utilities and raster-processing packaging examples.

Result

Both repositories expose source that can be inspected independently of employer systems.

Tools and methods

  • Python
  • GDAL
  • Rasterio
  • Docker
  • PDF processing

Independent portfolio tools

The raster work explores dependency packaging and compression. It is not presented as a validated production AWS Lambda deployment.

How it works

  • Convert selected PDF pages with configurable format, DPI, grayscale, and resizing options.
  • Explore Docker and Lambda-layer packaging for raster dependencies.
  • Include GDAL GeoTIFF compression source in the raster-processing repository.
